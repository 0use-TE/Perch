PERCH / 使用教程GETTING STARTED

01 / 下载安装INSTALL

一个文件，直接运行One file. Ready to run.

  1. 前往下载区。Intel / AMD 电脑选择 x64；骁龙等 ARM 电脑选择 ARM64。Visit Downloads. Choose x64 for Intel / AMD PCs, or ARM64 for Snapdragon and other ARM PCs.
  2. 把下载的 .exe 放到想保留的文件夹，双击运行。无需安装 .NET，也无需解压。Keep the downloaded .exe in a folder of your choice and double-click it. No .NET installation or extraction needed.
  3. 小岛会出现在主屏幕顶部。默认将鼠标移上去即可展开；移开后收起。The island appears at the top of your main display. By default, hover to open it and move away to close it.

02 / 设置小岛YOUR ISLAND

先调成你喜欢的样子Make yourself at home

  1. 展开小岛，点击右上角齿轮，进入设置 → 灵动岛。Open the island and click the gear at the top right. Go to Settings → Island.
  2. 选择「刘海」或「胶囊」，以及「纯黑」或「透明」材质。调整后立即生效。Choose a notch or capsule, then solid black or transparent material. Changes apply immediately.
  3. 在「功能」中开关页面、安排导航。没有固定在导航栏的页面，可从「…」里找到；若未出现，先确认该功能已开启。Use Features to enable pages and arrange navigation. Find unpinned pages under “…”; if a page is missing, check that its feature is enabled.
  4. 点击右上角图钉，可以保持展开。若希望点击才展开，可在灵动岛的行为设置中调整。Click the pin to keep the island open. To open on click instead of hover, change the island behavior settings.

03 / 日常使用EVERYDAY USE

把常用操作放手边Keep the essentials close

  • 待办与笔记：打开对应页面，添加任务或新建笔记。内容保存在本机。To-dos and notes: open their pages to add a task or create a note. Your content is saved locally.
  • 音乐与专注：播放音乐后打开音乐页控制播放；在专注页开始或暂停番茄钟。Music and focus: start music in your player, then use the music page for playback controls. Start or pause a Pomodoro from Focus.
  • 剪贴板：打开剪贴板页查看最近复制的内容，点击重新复制；置顶文字和文件可跨重启保留。Clipboard: view recent copies and click to copy again. Pinned text and files survive restarts.

Ctrl + Alt + I展开 / 收起小岛Toggle the island

Ctrl + Alt + N新建笔记Create a note

Ctrl + Alt + F全局搜索Global search

以上是默认快捷键，可在设置中修改。全局搜索可查找应用、待办、笔记和剪贴板。These are the default shortcuts; change them in settings. Global search finds apps, to-dos, notes and clipboard items.

04 / 小恐龙DINOSAUR

休息一下，跑个新纪录Take a break. Beat your best.

  1. 从导航栏或「…」打开「小恐龙」。找不到时，在设置 → 功能中开启。Open Dinosaur from the navigation bar or “…” menu. Enable it in Settings → Features if it is missing.
  2. 点击游戏区域或按空格开始。空格 / ↑ / W 跳跃，按得久一点跳得更高；↓ / S 蹲下，空中按下可加速下落。Click the game or press Space to start. Space / ↑ / W jumps; hold for a higher jump. ↓ / S ducks, or drops faster in mid-air.
  3. 躲开障碍，挑战最高分。碰撞后点击或按空格重新开始；切到其他页面或收起小岛会自动暂停。Avoid obstacles and chase your high score. Click or press Space to restart after a collision. Switching pages or closing the island pauses the game.

05 / AI 对话AI CHAT

接入模型，开始对话Connect a model. Start a conversation.

  1. 点击齿轮 → AI → 添加服务端，选择自己的服务，例如 DeepSeek、OpenAI、Ollama 或 LM Studio。Click the gear → AI → Add provider. Choose your service, such as DeepSeek, OpenAI, Ollama or LM Studio.
  2. 确认服务地址，填写该服务的 API 密钥。填好后会自动获取模型列表；本地服务需先在自己的电脑上启动，并使用它提供的 API 地址。Check the service URL and enter its API key. Perch fetches the model list automatically. For local services, start the service on your PC first and use its API URL.
  3. 打开「AI 助手」，在输入框下方选择模型，输入消息，点击右下角发送按钮。「新对话」可开始新的聊天。Open AI Assistant, choose a model below the input box, type a message and click Send at the bottom right. Use New chat to start another conversation.
  4. 需要时开启「深度思考」或「联网」。这些能力取决于所选模型及相关设置；联网搜索可在设置 → AI 中配置。Turn on Reasoning or Web when needed. Availability depends on your model and settings; configure web search in Settings → AI.
  5. 想让 AI 操作电脑时，在设置 → AI 中启用相关功能，并打开输入框下的「电脑」。执行前是否询问，取决于设置里的确认选项；在「执行前询问」中选择「每个操作」可逐次查看并允许或拒绝操作。To let AI work on your PC, enable computer tools in Settings → AI and turn on Computer below the input. Approval follows your settings; choose Every action to review and allow or reject each action.

在线模型需要你自己的服务账号或密钥，费用由服务商决定。发送的消息会交给你选择的模型服务处理。Online models use your own provider account or key, with pricing set by that provider. Messages are processed by the model service you choose.

06 / 常见问题HELP

遇到问题时If something gets in the way

找不到小岛了？Can't find the island?

先退出全屏应用，再按 Ctrl + Alt + I；也可以从系统托盘显示小岛。再次启动同一个程序会唤醒已有实例。Leave any full-screen app, then press Ctrl + Alt + I, or show Perch from the system tray. Launching the same app again wakes the existing instance.

AI 没有模型或无法回复？No models or no AI response?

检查服务地址、API 密钥和网络连接，并确认已选择模型。使用本地模型时，确认本地服务已运行。设置 → 日志 可查看和复制错误信息。Check the URL, API key and network, and make sure a model is selected. For local models, confirm the service is running. Open Settings → Logs to view and copy errors.

怎么退出或反馈问题？How do I quit or report an issue?

右键系统托盘中的 Perch 图标，选择退出。反馈问题请前往 GitHub Issues，附上复现步骤、系统架构和相关日志。Right-click the Perch tray icon and choose Quit. Report issues on GitHub Issues with steps to reproduce, your system architecture and relevant logs.
